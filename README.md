# 本町 Accessibility Lab

本町駅を対象に、エレベーター故障時の到達可能性とバリアフリー設備投資案を比較する、意思決定支援WebアプリのMVPです。

## できること

- 御堂筋線・中央線・四つ橋線のエレベーター停止を選択
- 到達可能率、移動不能OD、迂回時間、影響利用者を比較
- 3つの改善案について、費用・改善対象人数・年間削減時間を比較
- 改善前後の結果を表示

## 重要な注意

現在のネットワーク、移動時間、影響人数、工事費は、分析方法を検証するための仮説値を含みます。実際の移動案内には利用できません。公式構内図の精査、現地調査、事業者への確認後に更新する前提です。

## 起動

外部ライブラリやビルドは不要です。`index.html` をブラウザで開くか、任意の静的ファイルサーバーでこのディレクトリを配信してください。

## 次に必要なデータ

1. エレベーター・改札・ホーム・地上出入口の正確な接続
2. 各経路の移動時間、幅員、勾配、EV待ち時間
3. 設備故障時の運用と代替導線
4. 時間帯別・属性別の利用需要
5. 改善案の概算工事費
